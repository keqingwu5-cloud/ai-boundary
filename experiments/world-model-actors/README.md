# A001｜劇本演員世界模型隔離候選

狀態：**僅角色資料契約候選；未接上正式世界模型執行器；未合併；未部署。**

## 角色與工作目的
- 人物：第十三格・普通居民。照片僅作角色外貌參考；未經驗證的性格、習慣均為虛構設定。
- 場景：一般房間（床、枕頭、桌子、手機、水杯、筆記本、門）。
- 劇本：起身 → 喝水 → 閱讀筆記 → 補寫 → 結束。
- 外部干擾：通知、聲響、水杯移位；插入事件會打斷原步驟，但不能把原步驟算成完成。
- 注意：觀察到「手機亮起」只代表看見提示，不代表取得通知內容。

## 資料與權限
- `A001.actor.json` 為可審查的靜態角色候選；不是已經運行的 AI Agent。
- 不連結 `aiBrain.v1`、`worldModel.verify.v1`、GPT②、記憶資料或正式 DB。
- 不預設網路、付費 API、寫入、交易與部署權限。
- 匯入前先核對現有世界模型角色/事件/時間/證據欄位，保留原識別碼與歷史；不能把「行為推演」當成「真人特徵已驗證」。

## 接線候選（未實作）
1. world-model 場景只讀載入角色資料契約。
2. 劇本節點經由獨立 runner 產生事件，結果寫入獨立沙盒觀察日誌。
3. 人物視角只讀取 actor.known；上帝視角另看完整環境事實，兩者不混合。
4. 每步輸出 `source_type`、`observed_at`、`cause`、`effect`、`unknown` 與可重播情境 ID。
5. 先做隔離/負向/舊資料兼容測試，再提審；正式接線與部署須使用者再次核准。

## 本輪驗證的範圍
獨立本機 JavaScript 行為核心已以 Node assert 跑過六組驗證：三種情境可完成、中斷不偷推進度、知識限制、確定性重播與狀態隔離。**此分支目前只放置角色 JSON 與說明**，上述核心尚未併入倉庫，沒有瀏覽器端 E2E 證據。不能據此宣稱現有世界模型已支援演員。

## 停止條件
如發現錯用個人原始影像、跨模組狀態污染、錯誤因果歸因、未授權寫入或歷史資料覆蓋，立即停止整合，保留失敗證據，維持正式分支不變。
