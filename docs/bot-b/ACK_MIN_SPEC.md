# 獨立 ACK 最小測試規格 V0.1

## 定義
- 「收到」：接收端已持久化事件，且可被獨立查詢取得。
- 「未收到」：來源事件存在，但指定 inbox 在期限後仍無匹配紀錄。

## 最小案例
1. 來源有事件、inbox 無紀錄 → 必須報告缺口，不得宣稱已接收。
2. 來源有事件、inbox 有完全匹配 → 不得報告缺口。
3. 來源有事件、inbox 有同 ID 但內容不同 → 必須報告缺口。

## 證據要求
- 來源事件原始 bytes
- inbox 查詢結果原始輸出
- 固定 SHA
- 跨程序重跑可重現

## 注意
- 本規格不取代真實接收端。
- 無獨立執行環境的 ACK 仍為 UNVERIFIED。
- RELEASE_GATE = HOLD
