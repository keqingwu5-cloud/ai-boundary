# 接口相依與接線條件 V0.2

## 現在可以做 vs 真正需要等待

| 項目 | 現在可以做 | 真正需要等待 |
|---|---|---|
| BOT-B 指紋 | 取得固定 D01–D06 與 manifest 後比對內容 | 缺少的具體原檔或完整雜湊 |
| F05 接收接口 | 用合成來源驗證接口；明示不是實際來源測試 | 真來源測試所需的讀取管道；不限定必須 Webhook |

| Hatchet | 提出固定版本候選、依賴與選用理由 | Grok 確認共同版本後再做依賴該版本的接線 |

## 每項等待的細節

### BOT-B 指紋
- 缺什麼：D01–D06 與 VERSION_MANIFEST 的完整雜湊
- 向誰取得：BOT-A 分支
- 阻止哪一步：指紋比對的最終確認
- 取得後執行：比對並記錄差異

### F05 接收接口
- 缺什麼：真來源測試的讀取管道
- 向誰取得：需授權的來源存取
- 阻止哪一步：真實來源驗證
- 取得後執行：用真實事件重跑接口測試

### 橋樑 outbox
- 缺什麼：與 #97 events 表的欄位、交易、去重契約
- 向誰取得：契約負責人
- 阻止哪一步：outbox 與 events 的正式對接
- 取得後執行：核對欄位並實測去重

### 啟航 manifest
- 缺什麼：正式身份與授權
- 向誰取得：Merlin
- 阻止哪一步：正式環境啟動
- 取得後執行：在授權範圍內驗證 digest 綁定

### Hatchet
- 缺什麼：共同版本確認
- 向誰取得：Grok（整合）／Merlin（最終）
- 阻止哪一步：依賴該版本的接線
- 取得後執行：鎖定版本並更新依賴
