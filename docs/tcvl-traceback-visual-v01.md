# TCVL-04｜回溯驗證視覺原型 V0.1

## 定位

本分支只新增 `traceback-visual.html`，不更動 `memory.js`、`memory.html`、`launcher.html`、`memory-workflow-core.js` 或正式記憶庫。頁面為**純虛構示範**，可獨立開啟，用於討論介面與錄製展示影片。

### 展示三種回溯
1. **歷史回溯**：保留原主張、反證及版本來源。
2. **錯誤／影響回溯**：區分「引用依賴」與「已證實因果」，標出需要重新審查的記憶與任務。
3. **修正回溯**：把舊版和待核准候選並排，保留未解決條件與後續重測。

## 互動
- 五個可跳轉階段、上一階段／下一階段／重播／自動播放。
- 可見的虛構示範標籤、原始／修正前後對照、複製示範摘要。
- 手機版響應式排版；影片展示可按自動播放錄螢幕。
- 沒有向外部接口傳輸、沒有讀寫 localStorage、沒有讀取私有記憶。

## 本版未完成
- 不讀取實際的加密記憶，沒有動態依賴圖或證據真偽驗證。
- 未實作模型對話、實際測試執行、AI 身分驗證、時間隔離回測。
- 尚未通過手機與桌面實機瀏覽器驗收。
- 待後續設計實際事件 ID／版本 ID／時間戳／依賴關係的**唯讀、授權式**資料導入，需避免外洩私人資料。

## 手動驗收
- [ ] 手機開啟，五階段可點選、文字不溢出
- [ ] 下一階段／上一階段邊界停用正確
- [ ] 自動播放、暫停、重播正常
- [ ] 影響掃描階段顯示受影響節點而非直接宣稱因果
- [ ] 複製摘要可用／拒絕剪貼簿權限時有錯誤提示
- [ ] 無對外網路請求、無私人資料存取
- [ ] 返回記憶管理的超連結正確

本原型不得作為「已完成三方 AI 即時驗證」的商業證明。


## 2026-10-15｜測試邏輯 V0.1（新增，未合併）

新增 \`tcvl-traceback-core.js\` 和 \`tests/tcvl-traceback-core.test.cjs\`，視覺原型可載入核心，在**虛構示範資料**上執行三方處置測試及依賴影響追查。獨立 Node.js 測試結果：**19 項通過，0 項失敗**。此數字僅反映測試案例，不代表正式產品、三個 AI 或瀏覽器端已驗收。

### 純函式規則與邊界
- \`validateHistory\`：驗證 schema、唯一 ID、時間與依賴關聯；不證明來源真實。
- \`replayAt\`：僅顯示在截止時間前**已發生且已被系統記錄**的事件，防止事後資料混入歷史重建。
- \`impactOf\`：只沿 \`depends_on\` 連線反向追蹤，將可能受影響記錄標為「待重審／暫停」；不自動宣布結論錯誤，也不將 \`related_to\` 視為依賴。
- \`tripleCheck\`：GPT① 方向、GPT② 證據、BOT③ 條件變化，各必須帶結果及理由。可區分通過、失敗、未知、測試無效；**即使全部通過也不能自動核准**。
- \`reviewRejectedReuse\`：舊版否決 ID、原因、新證據、剩餘反證、重測範圍、責任歸因。僅做到欄位及 ID 可追溯，尚未進行證據真偽或內容一致性查核。
- \`compareRetests\`：只有研究案例、測試規則及資料截止時間一致才能比較通過／失敗；有未知或無效結果時不宣稱改善。此為單一測試比較，不代表普遍能力改善。
- \`validateMovement\`：檢查移動事件是否有進出來源、目的地、版本、校驗碼、時間、結果；**尚未真的計算雜湊或驗證資料傳輸**。

### 已執行的 19 個單元測試分類
- 歷史格式、重複 ID、關聯不存在檢查：3 項
- 指定時間點回溯、避免未來資訊外洩、不可變資料：3 項
- 依賴反向掃描、非依賴關係排除、暫停狀態、時間隔離：4 項
- 三方方向／證據／條件測試、退回與無效處理：3 項
- 被拒絕資料重新使用及新證據缺口：2 項
- 同條件修正前後比較與不可比性：3 項
- 匯入／匯出事件欄位檢查：1 項
