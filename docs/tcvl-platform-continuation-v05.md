# TCVL｜共用平台擴張與工作續接 V0.5

> 本版本先擴張設計與本機可操作流程，再做集中驗證。所有更新均在開發草稿分支，正式主站未合併。不存在遠端三方 AI 自動協作、跨頁私人工作資料同步或雲端服務承諾。

## 1. 使用者進入主腦後應看到什麼？

| 區域 | 主要作用 | 實際狀態 |
|---|---|---|
| 共用導航及設定 | 同一套入口開啟發射器、架構、三方交接、專案、回溯與記憶；提供圖片顯示選項和自訂狀態 | 已有本機 UI；共用資料只含顯示偏好與狀態名稱 |
| 停止指定工作 | 在專案治理選一筆任務，記錄進度後暫停；對話不受影響 | 本頁任務狀態可操作；不能遠端終止 ChatGPT／其他 AI |
| **工作續接卡**（本輪新增） | 整理專案目標、近期決策／待辦、未結任務、暫停進度及需處理的拒絕；可複製、匯出或在同專案建立新對話 | 本頁人工索引；不自動連接到其他 ChatGPT 聊天 |
| 拒絕／阻塞提醒 | 立即顯示原因、影響、下一步；可查看原紀錄，也可暫時收起上方提示 | 對本機新建／人工匯入的事件生效；已讀不代表解決 |
| 路徑與接口狀態 | 從節點看到人工交接／展示／規劃中的接口，路徑反轉及依賴關係 | 靜態規格，不代表即時 API 健康度 |
| 未啟用版塊 | 用虛化候選節點展示未來方向，保留既有路徑和版本 | 候選設計，非功能啟用 |
| 圖片設定 | 顯示、淡化或隱藏一般圖片；顯示完整或裁切填滿 | 本機共用 UI 偏好，不是圖片生成器或檔案上傳設定 |

## 2. 工作續接怎麼使用？

1. 到「專案治理」，建立或選擇專案，並記錄任務、進度、決策、待辦與拒絕原因。
2. 如需停止某項工作，在「工作與停止控制」選定指定任務，先填入進度，再按「停止指定工作」。**這只記錄本頁的暫停狀態，不向遠端 AI 發送停止訊號。**
3. 到「工作續接卡」，可按「更新續接摘要」。內容包含當前專案、來源對話、最近部分決策及待辦、未完成工作與未讀拒絕／阻塞。
4. 按「在同專案開新續接對話」，系統會建立新對話並寫入一張**人工生成的工作索引**，但保留原對話、原決策、原任務及其暫停狀態。
5. 跨頁或進入其他聊天工具，須經使用者確認才能複製續接文字、下載未加密的索引 JSON。這不是自動同步或 AI 接收證明。
6. **離開／重新整理前，務必下載完整工作空間 JSON。** 續接卡只取最近部分紀錄以方便閱讀，不能替代完整封存。跨頁使用需手動匯入；若要進入主腦正式記憶還需匯出待審記憶包後，由使用者在本機加密記憶頁核准。

## 3. 拒絕提醒與多專案隔離

- 原本的任務拒絕、阻塞、未來候選版塊拒絕及三方交接拒絕，都要求原因、影響與下一步。
- 本輪新增 **projectId** 來源標記，讓後續拒絕事件可歸屬專案，避免新建事件混到無關專案的提醒。
- 舊版沒有 projectId 的事件，在能依現有任務 ID／候選 ID 找到原專案時才顯示；無法確認歸屬者不自動猜測。
- 選擇專案、匯入工作空間後，若有未讀事件會主動顯示本專案最近一則原因／影響／下一步，其餘事件仍在提醒清單中。
- 共用頂部提示有「查看詳情」與「暫時收起」。**暫時收起不會變更警報本身的已讀／待處理狀態。**

## 4. 不讓對話突然切斷工作的規則

- 專案 → 多個對話 → 多個任務（各自有狀態與歷史）。新對話可以接續相同專案，但**沒有權限替已暫停任務標記完成或直接恢復工作**。
- 新續接對話記錄 parentThreadId 與來源索引、專案 ID、當前未結任務數、未讀拒絕數；原本完整對話不會被取代。
- 真正讓其他 AI 自動續接或中止其執行，需要未來另外部署安全的 AI 連接器及具停止／回報確認的後端；此版本未實作。
- 自訂狀態選項是共用**顯示名稱**，必須對應已知基礎狀態；不能把規劃接口標成「已真實連線」。

## 5. 此輪集中驗證範圍

本輪補充的測試主要對準：
- 同專案建立續接對話後，原任務仍暫停，進度與來源對話保留；
- 專案決策、待辦、提醒在續接卡上可查；
- 不可把其他專案的對話／拒絕帶入目前專案；
- 已讀提醒不刪除原始事件；
- 預設路徑仍保留人工交接和未啟用的狀態分類。

**待正式驗收：** iPhone Safari／桌面 Chrome 操作、工作空間 JSON 實際下載／再匯入、實際本機加密記憶操作、與 PR #27 的記憶備份相容性、真實 AI API 收發／停止，以及整體安全與可存取性測試。

## 6. 隱私與商業邊界

共用的顯示設定可能寫入瀏覽器 localStorage，僅存圖片偏好及自訂狀態標籤。專案、對話和任務仍只在專案頁記憶體，除非你明確下載未加密的 JSON 並人工匯入其他服務。不要把機密資訊放進公開展示或共用狀態名稱。

公開儲存庫裡的 JavaScript 原始碼可被查閱；公開展示影片沒有顯示程式碼，也不等於技術上已保密。
