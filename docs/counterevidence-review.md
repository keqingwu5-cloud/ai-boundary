# 反證審查｜接收方使用
觸發：已收到通過自審的交付，且受指派做獨立審查。
1. 核對受審版本、原始主張與證據範圍；不要把提出者的自審或共用帳號留言當成獨立驗收。
2. 優先找**一份足以區分多個重要疑問的關鍵證據或反例**，並明確列出它能解決哪些問題、哪些問題仍未解；這不是固定一份、固定題數或固定上限。依新證據、版本與風險調整檢查。每次新增都要指出既有證據缺口、可重用原件及能改變哪項 Gate。
3. 有充分同版證據時直接重用並給出限縮結論；只補最小有判別力的測試，避免無效重跑。
4. 回覆可接受、需修正或證據不足，附原件與依據。後續只複核受影響部分；證據已足或因缺環境而受阻就停止，不進行無上限審查。
5. 真實目的端身分、執行回執與來源讀回尚未證明時，維持 `TRUSTED_ACK=BLOCKED`；自我檢查與獨立驗收始終分離。

一份證據能同時支持多個主張，並不等於多份獨立證據；審查需逐項核對條件、版本與邊界，保留原件、仍未解除的疑慮及改判理由。
