# 第一大腦｜記憶方向驅動的動態認知 V0.1（候選設計）
狀態：設計規格，未實作執行器，未部署或改寫正式記憶。
上位文件：docs/drafts/first-brain-architecture-operations-v1.0.md

## 核心決策
記憶提供長期方向、歷史因果、已驗證能力與限制；當前情境提供新的證據與約束。規劃器比較兩者後選擇最小可驗證路徑，不能直接把歷史紀錄當成執行指令。

## 記憶分層
1. 方向記憶：目標、優先順序、不可偏離的架構定位；修改需有版本與決策來源。
2. 治理記憶：授權、禁止事項、部署邊界；記憶內容不是授權憑證。
3. 能力記憶：零件、契約、依賴、版本、能力成熟度；候選與正式分離。
4. 因果記憶：前提、採取行動、預期、實際結果、證據、反例、根因。
5. 情境記憶：任務當下狀態、時效、來源、環境差異；不得永久視為有效。
6. 事件記憶：追加式紀錄每次評估、執行、阻塞、回滾及升級。

## 循環
A. 載入版本化方向及授權邊界。
B. 檢索相關能力、歷史與當前情境，檢查時效及來源。
C. 產生前提與缺失後果，區分事實、假設、未知。
D. 形成多個候選路徑：重用、補資料、隔離測試、替代或停止。
E. 比較方向符合度、依賴、風險、成本、可逆性與可驗證性。
F. 在允許範圍內執行最小步驟；高影響操作需獨立授權。
G. 對照原成功標準，分開報告動作完成、輸出有效、接收確認、目的達成。
H. 追加結果及證據，更新可修正的認知；重大方向改變只提出建議，等待核准。

## 衝突優先序
明確有效授權與不可繞過治理 > 已核准的方向版本 > 新鮮且可信的當前事實 > 經驗性策略 > 未驗證假設。
如歷史方向與當前證據衝突：暫停衝突步驟、提出替代路徑和方向修訂提案，不自行覆寫方向記憶。
不同目標衝突：顯示取捨與證據，不以模型信心自行變更最高優先級。

## 最小驗收情境
- 同一目的、不同情境：能選不同候選路徑，方向不變。
- 舊歷史成功但新版本契約不相容：拒絕直接重用。
- 歷史推論與新證據衝突：保留原始事件、產生待審修正。
- 缺可信 ACK：不宣稱接收成功。
- 方向記憶內容含「直接部署」但沒有授權：仍不可部署。
- 過期證據、依賴循環、未知零件：明確阻塞與報告。
- 重複修補無新證據：改走根因檢查，不盲目重試。
- 讀取既有 aiBrain.v1：遷移前備份、無損驗證、回滾。
