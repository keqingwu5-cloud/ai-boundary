# 第一大腦｜總體架構與運營基準 V1.0
狀態：獨立候選治理藍圖，未合併、未部署、未啟動正式排程。
日期：2026-10-26

## 方向與成功定義
建立「記憶 → 任務認知 → 能力與依賴調度 → 隔離執行 → 證據驗收 → 回寫記憶 → 架構修正」的閉環。
最小實作服從完整架構；禁止以零件數量、PR 數量或模擬 ACK 當成運作成功。
使用者負責方向、重大取捨與受保護操作授權；系統負責一般前提檢查、既有能力檢索、測試證據整理與異常回報。

## 層級與契約
L0 治理與權限：目標、政策版本、角色/授權、資料保護、發布閘門、回滾；禁止自授權。
L1 記憶與歷史：原始前因、來源、事件、版本、關聯索引；先保留既有 aiBrain.v1，不覆寫。
L2 認知與推演：目標、必要條件、缺失後果、假設/反證、未知；現有 task-cognition 候選。
L3 零件與依賴：part_id、版本、輸入/輸出契約、依賴圖、能力/限制；現有 brain-part-registry 候選。
L4 工作調度與隔離：路由到 GPT/BOT/外部接收端，驗證真實 ACK；目前不能宣稱 GPT② 真實端到端可用。
L5 執行與環境：獨立測試、CI、部署前檢查、正式部署、回滾；本階段只允許候選與隔離測試。
L6 觀測與升級：成功/失敗/阻塞、根因、回歸、事件回寫；現有 cognition-exploration 候選。
L7 世界模型應用：角色、力量流動、因果路徑、情境推演；依賴 L1–L6，不提前當成已上線。

## 所有新需求的固定判斷程序
1. 對照總體目標、歸屬層級與成功定義。
2. 查找現有零件、歷史問題、既有測試；無證據不得稱「已解決」。
3. 識別輸入、輸出、資料版本、依賴、授權與缺失影響。
4. 評估不做、重用、替代、最小新增的後果；保留反向/側向假設。
5. 選最小可驗證切片；先列正向、負向、舊資料、跨模組測試。
6. 取得真實測試輸出與 SHA；阻塞時記錄缺失與責任界線。
7. 受保護操作必須重新驗證並取得明確授權，不能由候選模組自行放行。
8. 追加式回寫結果與新證據，必要時修訂總體架構。
