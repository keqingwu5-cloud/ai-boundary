## 任務本意（2026-10-27）
世界模型第一優先；同一組「研究事件／版本鏈」案例，同時辨識 **第一大腦本體、世界模型本體、連接層** 哪邊出問題。先按資金需求排列測試，避免實機測試時才反覆重做底層修復。這不是投資建議或資產操作。

## 三個完全分開的被測物

## 合成版本鏈：非線性，不覆寫
\`\`\`text
v1 evt:h1 合成原假設
   ├── v2 evt:o1 發布於 2026-04-10 的合成觀察
   │       └── v3 evt:r1 修正（原文不覆寫）
   └── v4 evt:b1 從舊中間節點建立替代分支
           └── v5 evt:c1 2026-07-15 才可取得的合成反例
\`\`\`
- **所有事件實際記錄日設定為 2026-10-27**，不是宣稱當年系統存有 v1。
- 事後回溯 \`2026-07-01\` 可用的資料只包含 v2 合成觀察，不包含未發布的 v5；當時實際系統留存版本仍是 **0**。
- 每個事件有 \`research_id\`、\`event_id\`、\`node_id\`、\`parent_event_id\`、\`branch_id\`、\`version\`、\`kind\`、\`observed_at\`、\`published_at\`、\`recorded_at\`、\`provenance\`；修正必須保留 \`reason\`。
- \`research-event-chain.mjs\` 僅為純函式／合成測試核心，**不存入 \`worldModel.verify.v1\`、\`aiBrain.v1\`、記憶庫或付費金融平台**。世界模型頁新增的雙系統面板對正式資料只讀。

## 已查到的風險及未開發項目
1. 世界模型既有狀態選單會直接改 \`worldModel.verify.v1\` 中的 \`status\` 值；刪除及匯入也會改／取代本機紀錄。**現有正式 v1 紀錄尚無完整不可覆寫版本鏈**。本輪只用合成模型先建立 Gate，不私自更動舊版資料格式。
2. 第一大腦與 Feed 的來源 ID 可連，但這是同源 localStorage，不是獨立證據審查，也無跨裝置資料同步。
3. 世界模型內的 CPI、FOMC、價格等是既有靜態研究子集；**本輪只測時間邏輯和計算，沒有重新向官方核驗每筆原始數字或認證 30 年回測**。
4. 日期、研究資訊或 status 顯示正確不等於已核准，尤其不可讓 \`synthetic_fixture\` 被報成外部確證。
5. \`localStorage\` 不能保證真正跨分頁原子性；獨立 BOT③ 或 GPT② 已 ACK 仍無證據。
